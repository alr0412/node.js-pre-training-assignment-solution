5. EXPLANATION OF VOLUME TYPES
------------------------------
- Named Volumes: Managed entirely by Docker daemon and stored in host isolation. Retain data even when source containers are deleted. Ideal for persistent services like databases.
- Bind Mounts: Map an absolute filesystem directory from the host machine directly into the container. Primarily used in development for hot-reloading code changes instantly.
- Tmpfs Mounts: Store files strictly inside host system memory (RAM). Data never persists on persistent storage disks and is automatically destroyed upon container state resets or reboots.
